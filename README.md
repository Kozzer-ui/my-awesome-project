# 🚀 My Awesome Project

> 学习 GitHub API 仓库 — 通过 OpenClaw 自动创建和管理

## 📖 项目简介

这是一个用于学习 **GitHub API** 的实践项目，涵盖了以下内容：

- ✅ GitHub REST API 基础操作
- ✅ 仓库创建与管理
- ✅ 分支管理（Branch）
- ✅ Pull Request 工作流
- ✅ Issues 与项目管理
- ✅ GitHub Actions 自动化

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| **GitHub API v3** | REST API 接口 |
| **GitHub API v4** | GraphQL API |
| **PowerShell** | 自动化脚本 |
| **OpenClaw** | AI 助手集成 |
